Menimpa Warisan

Class turunan dapat menyesuaikan cara kerja method yang diwariskan, sekaligus tetap memanggil versi induknya bila diperlukan.

Durasi: 120 menit Prasyarat: extends & super() (Pertemuan 4) Bahasa: JavaScript (ES6+)
1

Warisan yang Tidak Cukup Apa Adanya

Resep turunan nggak selalu bisa dipakai persis sama dengan resep dasarnya, kan. Resep dasar bilang "panggang 30 menit" — tapi kue yang lebih tebal butuh waktu beda. Sama juga dengan method yang diwariskan: kadang perilakunya perlu diubah sesuai kebutuhan class anak.

Coba lihat masalahnya di bawah ini: Lingkaran mewarisi luas() dari Bentuk, tapi versi warisan itu nggak tahu rumus luas lingkaran gimana.

warisan-tidak-cukup.js
class Bentuk {
  constructor(nama) {
    this.nama = nama;
  }
  luas() {
    console.log("Luas belum bisa dihitung untuk bentuk umum");
    return 0;
  }
}

class Lingkaran extends Bentuk {
  constructor(jariJari) {
    super("Lingkaran");
    this.jariJari = jariJari;
  }
  // belum meng-override luas() -> masih pakai versi Bentuk yang generic
}

const bulat = new Lingkaran(7);
console.log("Hasil (salah):", bulat.luas());
Klik "Jalankan" untuk melihat masalahnya.
2

Method Overriding

Solusinya gampang: tulis ulang (override) method luas() di dalam Lingkaran dan PersegiPanjang, masing-masing pakai rumusnya sendiri. Tinggal definisikan method dengan nama yang sama — JavaScript otomatis pakai versi milik class yang paling spesifik.

override-luas.js
class Bentuk {
  constructor(nama) {
    this.nama = nama;
  }
  luas() {
    return 0;
  }
}

class Lingkaran extends Bentuk {
  constructor(jariJari) {
    super("Lingkaran");
    this.jariJari = jariJari;
  }
  luas() { // override
    return Math.PI * this.jariJari ** 2;
  }
}

class PersegiPanjang extends Bentuk {
  constructor(panjang, lebar) {
    super("Persegi Panjang");
    this.panjang = panjang;
    this.lebar = lebar;
  }
  luas() { // override
    return this.panjang * this.lebar;
  }
}

const bulat = new Lingkaran(7);
const kotak = new PersegiPanjang(5, 3);

console.log(`${bulat.nama}: ${bulat.luas().toFixed(2)}`);
console.log(`${kotak.nama}: ${kotak.luas()}`);
Klik "Jalankan" untuk melihat hasilnya.
Aturan wajib nih: tiap class turunan Bentuk yang mau punya luas yang benar, HARUS meng-override luas() sendiri — soalnya nggak ada satu rumus luas pun yang cocok buat semua bentuk sekaligus.
3

super.method() & instanceof

Kadang class anak nggak mau ganti total perilaku induknya, cuma pengen nambahin sesuatu aja. Nah di sinilah super.namaMethod() berguna — jalankan dulu versi milik induk, baru tambahin kode sendiri.

instanceof berguna buat mastiin sebuah objek beneran "keturunan" dari class tertentu.

super-dan-instanceof.js
class Bentuk {
  constructor(nama) {
    this.nama = nama;
  }
  info() {
    console.log(`Ini adalah bentuk bernama ${this.nama}`);
  }
  luas() {
    return 0;
  }
}

class Lingkaran extends Bentuk {
  constructor(jariJari) {
    super("Lingkaran");
    this.jariJari = jariJari;
  }
  info() {
    super.info(); // tetap jalankan info() bawaan dari Bentuk dulu
    console.log(`Jari-jarinya ${this.jariJari}`);
  }
  luas() {
    return Math.PI * this.jariJari ** 2;
  }
}

const bulat = new Lingkaran(7);
bulat.info();

console.log("Apakah bulat adalah Lingkaran?", bulat instanceof Lingkaran);
console.log("Apakah bulat juga adalah Bentuk?", bulat instanceof Bentuk);
Klik "Jalankan" untuk melihat hasilnya.

Latihan: Pajak Kendaraan yang Berbeda

Yuk lanjutin proyek Kendaraan dari Pertemuan 4. Override hitungPajak() di Mobil (3% dari harga) dan Motor (1% dari harga), beda dari versi umum di Kendaraan (2%).

latihan-pajak.js — bisa diedit
Lengkapi kode lalu klik "Jalankan".
kunci-jawaban.js
class Mobil extends Kendaraan {
  constructor(merek, hargaKendaraan, jumlahPintu) {
    super(merek, hargaKendaraan);
    this.jumlahPintu = jumlahPintu;
  }
  hitungPajak() {
    return this.hargaKendaraan * 0.03;
  }
}

class Motor extends Kendaraan {
  constructor(merek, hargaKendaraan, tipe) {
    super(merek, hargaKendaraan);
    this.tipe = tipe;
  }
  hitungPajak() {
    return this.hargaKendaraan * 0.01;
  }
}
5

Cek Pemahaman

1. Sebenarnya "method overriding" itu apa sih?

Nama method-nya sama, tapi isinya beda — versi paling spesifik (di class anak) yang dipakai.

2. Fungsinya super.info() di dalam method info() milik class anak itu apa?

super.info() manggil versi induk secara eksplisit, biasanya buat "nambahin", bukan "ganti total".

3. Kegunaan instanceof itu buat apa?

bulat instanceof Bentuk hasilnya true, soalnya Lingkaran itu turunan Bentuk.

4. Kenapa Lingkaran dan PersegiPanjang WAJIB meng-override luas()?

Rumus luas lingkaran dan persegi panjang beda total — nggak ada satu rumus umum yang cocok buat keduanya.
Skor: 0 / 4 terjawab benar
6

Ringkasan Pertemuan 5

  • Method overriding bikin class anak bisa ganti perilaku method yang diwariskan, dengan cara mendefinisikan ulang method bernama sama.
  • super.namaMethod() jalanin versi induk lebih dulu, berguna kalau class anak cuma mau nambahin, bukan ganti total.
  • instanceof ngecek apakah suatu objek itu instance dari class tertentu atau turunannya.
  • Class induk yang generic (kayak Bentuk) sering sengaja dibuat "belum lengkap" — ngandelin tiap class anak buat meng-override method yang bener-bener spesifik.
Selanjutnya

Di Pertemuan 6 bakal kelihatan kekuatan aslinya dari override ini: satu baris kode bisa manggil .luas() ke banyak bentuk beda-beda sekaligus, tanpa perlu tahu bentuk spesifik yang mana — itulah Polymorphism.
