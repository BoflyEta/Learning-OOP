Ringkasan Kelas

Prasyarat

Variabel, tipe data, function, array, object literal, dan loop dasar di JavaScript.

Tujuan Umum

Kamu akan mampu merancang dan menulis program JavaScript menggunakan class, serta menjelaskan alasan di balik setiap pilar OOP.

Analogi Kunci

Class adalah cetak biru (blueprint); object adalah bangunan nyata yang dibuat dari cetak biru itu.

Penilaian

Latihan di setiap sesi, keaktifan dalam diskusi, serta proyek akhir dan presentasinya.

Panduan Belajar

Tips Belajar OOP

  • Gunakan analogi dunia nyata secara konsisten. Anggap class sebagai cetak biru rumah dan object sebagai rumah yang sudah dibangun, lalu gunakan kembali analogi ini saat mempelajari konsep baru.
  • Mulailah dari kode procedural yang sudah kamu kenal, lalu ubah secara bertahap menjadi OOP. Jangan langsung memulai dari sintaks class yang kosong.
  • Pahami setiap pilar OOP melalui masalah nyata terlebih dahulu, seperti kode yang berantakan, duplikasi, atau bug, sebelum mempelajari solusinya.
  • Gunakan checkpoint di setiap sesi untuk memeriksa pemahaman dan menemukan bagian yang masih membingungkan sejak awal.
